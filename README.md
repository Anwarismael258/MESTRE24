# Mestre24

Site oficial do Mestre24 — encontre quem sabe fazer.

## Conteúdo

- `index.html`: página institucional e apresentação do aplicativo móvel.
- `termos.html`: termos de utilização.
- `privacidade.html`: política de privacidade resumida.
- `assets/logo-mestre24.png`: identidade oficial.
- `.github/workflows/pages.yml`: publicação automática no GitHub Pages a cada push em `main`.

## Publicação

Depois de activar o GitHub Pages com a origem **GitHub Actions** em `Settings → Pages`, cada push para `main` publica o site em:

`https://anwarismael258.github.io/MESTRE24/`

O botão do aplicativo aponta para as releases do repositório até existir um APK de produção anexado.
